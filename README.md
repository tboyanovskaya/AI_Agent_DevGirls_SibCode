# AI Agent — DevGirls SibCode

**Кейс 1: AI-driven интерфейс управления рекламными кампаниями (MVP)**

Прототип AI-агента, который позволяет управлять рекламными кампаниями через естественный язык. Пользователь формулирует задачу — агент интерпретирует её, вызывает нужные инструменты и возвращает результат.

---

## Возможности

- **Диалоговый интерфейс** — управление кампаниями на естественном языке
    
- **AI-агент** на базе LLM с поддержкой function calling, human-in-the-loop и сохранением состояния.
    
- **Генерация креативов** — генерация шаблона текста на фоне-заглушке.
    
- **Мок-данные** — готовый набор тестовых кампаний для демонстрации
    
- **REST API** на FastAPI
    
- **Docker-развёртывание** — запуск одной командой

## Быстрый старт

### Локальный запуск

```bash
git clone https://github.com/tboyanovskaya/AI_Agent_DevGirls_SibCode.git
cd AI_Agent_DevGirls_SibCode
pip install -r requirements.txt```
```
Задайте переменные окружения (ключи API LLM / Kandinsky) — см. раздел «Конфигурация».
Запуск FastAPI-сервера:

```bash
uvicorn fast_app:app --reload
```

Запуск интерфейса:

```bash
python app.py
```
### Запуск через Docker

```bash
git clone https://github.com/tboyanovskaya/AI_Agent_DevGirls_SibCode.git
cd AI_Agent_DevGirls_SibCode
docker compose up --build
```

## Основные компоненты

| Файл          | Назначение                                                                |
| ------------- | ------------------------------------------------------------------------- |
| `agent.py`    | Ядро агента: обработка запроса, вызов инструментов, формирование ответа   |
| `tools.py`    | Набор доступных агенту действий (создание/редактирование кампаний и т.п.) |
| `schemas.py`  | Валидация входных/выходных данных                                         |
| `fast_app.py` | HTTP-эндпоинты для интеграции                                             |
| `prompts/`    | Системные промпты и шаблоны                                               |
